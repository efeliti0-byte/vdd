# vdd

Proyecto web con servidor nativo Node.js (sin dependencias externas).

## Requisitos

- [Node.js](https://nodejs.org/) (versión 14 o superior)

## Cómo iniciar el servidor

1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta:
   ```bash
   npm start
   ```
   o directamente:
   ```bash
   node server.js
   ```
3. Abre tu navegador en la URL indicada en consola (por defecto: `http://localhost:3000` o `http://localhost:3001` si el 3000 está ocupado).
